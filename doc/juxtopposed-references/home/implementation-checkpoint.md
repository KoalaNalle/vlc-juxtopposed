# Home dashboard and native activity checkpoint

14 October 2026. Original design/artwork: [Juxtopposed](https://www.youtube.com/@juxtopposed). [Reference notes](reference-notes.md) retain original frames and provisional measurements. Full visual acceptance remains open.

The redesigned Home now connects Continue Watching, Listen Again, Frequently Visited Folders, Frequently Visited Playlists and Frequently Listened Artists to the actual media library. Recent audio has its own native audio-history model. Continue Watching retains native resume options. See All uses virtualized collection views; the dashboard creates only four activity preview cards even when a collection contains 250 entries. Mixed folder contents use the native media model rather than an audio-only or video-only substitute.

Folder and playlist rankings use successful native-ID-validated navigation visits, persisted separately from media completion counts. Artist rankings aggregate the complete paginated native audio set, using native play counts and last-played dates. Missing/deleted/banned records, unavailable folders, loading and persistence errors retain explicit states. Turning off recent-play recording prevents new visits. Clear History clears visits and invalidates earlier queued visit callbacks; Reset Preferences clears the cached store so old records cannot reappear on the next visit. Ordinary preference saves preserve activity.

MediaLib owns the activity service and destroys it before its worker runner. Settings writes occur on accepted visits, not during teardown. Refresh and visit generations reject obsolete work. Both build systems register the model, service, QML and native diagnostic. The Autotools QML dependency generator now supplies the module resource file to `.js` and `.mjs` cache compilation as well as `.qml`; the new sorting script exposed that missing dependency.
