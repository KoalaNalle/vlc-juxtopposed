# Design references and verification evidence

Active development starts at [the project guide](../juxtopposed/README.md).
[BETA](../juxtopposed/BETA.md) owns current scope and completion gates;
[STATUS](../juxtopposed/STATUS.md) owns the current runtime and next action.

This tree preserves original assets/manifests and dated implementation, test and
review receipts. Each result has its own source, binary, fixture and platform
scope. Preserve frozen contents and recorded identities. Later passes do not
rewrite earlier failures or automatically qualify another package.

The older `coverage-ledger.md`, `beta-readiness-20261018.md` and
`setup-customization-20261018.md` are historical reference/coverage snapshots.
Their implementation labels and resume links can predate newer fixes. Use them
for provenance and recorded evidence, not as current work instructions. Old
links to superseded plans can be resolved through the
[archive map](../juxtopposed/archive/README.md) or their recorded Git revision.
The reference artifacts themselves remain in their existing paths.
