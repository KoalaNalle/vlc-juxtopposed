All nineteen supplied SVGs were downloaded exactly as instructed by the response.
[manifest.json](manifest.json) records original file lengths, SHA-256 and root
dimensions. The information asset is 18 × 18; the other supplied artwork is
24 × 24. None was redrawn, edited or substituted. Runtime settings must reuse
original bytes and intrinsic artwork geometry while adapting layouts to Qt.

does not establish native implementation, protocol/security behavior, visual
